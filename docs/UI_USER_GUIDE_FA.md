# راهنمای رابط WALL-E

```powershell
conda run --no-capture-output -n shbk python -m wallex_bot.atlas_console --port 8766
```

نشانی: http://127.0.0.1:8766 — فقط localhost. برای توقف Ctrl+C. مرورگر فارسی RTL و انگلیسی LTR است و در عرض کوچک navigation به بالای صفحه منتقل می‌شود. UI فقط‌خواندنی است؛ نه کلید می‌خواهد، نه حافظه را می‌نویسد، نه collector یا LIVE را شروع می‌کند.

- نمای کلی: cash فرضی جدا از حساب واقعیِ تأییدنشده، lease واقعی collector، تاریخ snapshot، موعد و وضعیت ساعت. قدیمی‌بودن داده با قطعی شبکهٔ فعلی یکی نیست.
- بازار: انتخاب نماد و 1m/5m/15m/30m/1h/4h/1D؛ تنها کندل بستهٔ SHA/grid تأییدشده، بدون gap-fill. شواهد Ichimoku/Fibonacci/SuperTrend از تصمیم ذخیره‌شده برچسب تاریخی دارد، نه محاسبهٔ جاریِ بی‌مدرک.
- پژوهش AI: کوانتایل پنج مدل، وضعیت مؤثرِ فقدان quote سررسید بدون تغییر DB، اخبار واقعی با تاریخ دسترسی/لایسنس، حافظه و الگوهای مشابه با خطوط نرمال‌شدهٔ واقعی ایندکس. نمودار Pattern پیش‌بینی قیمت نیست.
- پرتفوی: موقعیت واقعی کاغذی، cash، NAV آخرین receipt با برچسب تاریخی و allocation. real NAV/PnL و سفارش‌های واقعی بدون احراز حساب مقدار ساختگی نمی‌گیرند.
- شواهد: ده نقش، اختلاف، veto، trace، replay/backtest، Sync، rubric و audit انتشار. Export فقط گزارش‌های عمومی allowlist است، نه مسیری دلخواه به filesystem یا حساب.
- فهرست ابزارها: جست‌وجو در module، شرح و گزینه‌های کشف‌شده؛ کپی فرمان برای ترمینال. سرویس بدون argparse را با راهنمای --help اشتباه نگیرید. کپی/دیدن فرمان مجوز اجرای مالی نیست.

نبود archive/checkpoint با DATA_NOT_AVAILABLE نمایان می‌شود. نبود دادهٔ سفارش، نبود سفارش واقعی را ثابت نمی‌کند. عدد ۵میلیون Shadow اعتبار تأییدشدهٔ مسابقه نیست. هیچ دکمهٔ LIVE صوری، Secret در localStorage یا دانلود مدل خودکار وجود ندارد. UI از Stack قبلی stdlib HTTP + HTML/CSS/Canvas استفاده می‌کند؛ فریم‌ورک جدید نصب نشد.
