# روش‌شناسی جست‌وجوی الگوهای تاریخی

نسخه: `ATLAS_ANALOGUES_V1`. این ابزار پژوهشی است، نه تضمین تکرار بازار و نه مجوز سفارش.

## ورودی و نمایش

فقط Chunk واقعی والکس با SHA صحیح، grid معتبر، بدون نسخه‌های متعارض و کندل بسته پذیرفته می‌شود. Gap قطعه را جدا می‌کند؛ حجم صفر و کندل بدون Range با قیمت/حجم مصنوعی جایگزین نمی‌شوند. هر ترکیب دارایی/تایم‌فریم متعارض مستقل کنار گذاشته و دلیل نگه‌داری می‌شود.

طول‌های ۷ و ۱۰ در ایندکس و ارزیابی واقعی استفاده شده‌اند؛ ۱۶ و ۲۴ در قرارداد Build قابل انتخاب‌اند ولی برتری‌شان آزمایش نشده است. رزولوشن‌ها 1m/5m/15m/1h/4h هستند؛ نبود پنجره معتبر برای یک رزولوشن، نتیجه Missing است، نه موفقیت پوشش آن.

دو نمایش مستقل:

- `relative_ohlcv`: log(OHLC / close ابتدای پنجره)، تقسیم بر انحراف معیار بازده‌های همان پنجره؛ log1p(volume) منهای log1p(median volume) همان پنجره.
- `candle_structure`: بازده داخل کندل، log(H/L)، بدنه و سایه‌ها نسبت به Range و حجم نسبی. مخرج صفر یا نوسان/Median حجم صفر، وضعیت صریح undefined دارد.

هیچ scaler یا encoder روی کل سری یا آینده Test fit نشده است. قیمت عددی مطلق معیار شباهت نیست.

## جست‌وجو و منابع

فاصله اقلیدسی مستقیماً با `scipy.spatial.distance.cdist` محاسبه می‌شود. DTW مستقل با قید Sakoe–Chiba شعاع ۲ و فاصله‌های SciPy، نقطه شروع/پایان ثابت و تقسیم بر n+m اجرا می‌شود. برای سقف کار، DTW فقط ۵۱۲ همسایهٔ اولیه اقلیدسی را بازرتبه‌بندی می‌کند؛ این **DTW تقریبی با Prefilter** است، نه جست‌وجوی دقیق DTW در تمام کاندیداها. معیار ساختار کندل و Baseline تصادفی تاریخی با Seed ثابت نیز وجود دارند.

فیلترها: همان دارایی/همه دارایی‌ها، رزولوشن، طول، رژیم توصیفی، بازه نوسان و تاریخ مجاز. فیلتر نقدشوندگی بدون Book واقعی تاریخی صریحاً Insufficient است؛ حجم کندل نقدشوندگی قابل اجرا فرض نمی‌شود. FAISS یا encoder اضافه نشده، زیرا داده/کارایی مستقل لازم برای توجیه آن‌ها احراز نشده است.

اطلاعات مجوز و منبع در `third_party/SOURCES.md` است. مستند الگوریتم محدود DTW: [مرجع رسمی librosa](https://librosa.org/doc/0.10.2/generated/librosa.sequence.dtw.html). Probe محلی librosa تکمیل نشد؛ اجرای موفق آن ادعا نشده است.

## PIT و استقلال

Candidate فقط وقتی مجاز است که تمام پنجره و انتهای Outcome دوازده‌بارِ آن، با یک بار Embargo، پیش از شروع پنجره Query باشند. زمان دسترسی نیز باید <= زمان تصمیم باشد. Outcomeهای ۱/۳/۶/۱۲ کندل از کندل واقعی هستند و شامل Close-return، MFE، MAE، Range و شماره کندل وقوع Extremum می‌شوند؛ هیچ‌کدام PnL اجرایی نیستند.

برای legacy با زمان دریافت تاریخی نامعلوم، فقط «اکنون این بایت‌ها تأیید شدند» ثبت می‌شود. چنین داده‌ای برای تصمیم امروز مجاز است، اما دسترسی دیروز را ثابت نمی‌کند. بازوی retrospective صریحاً `RETROSPECTIVE_CANDLE_RESEARCH_NOT_PROVEN_PIT` نام دارد؛ نباید مطالعه واقعاً PIT یا آینده‌نگر معرفی شود.

Top-K از نظر بازه کامل Pattern+Outcome، حتی میان دارایی‌های متفاوت، هم‌پوشانی زمانی ندارد. شمار مؤثر، شمار این بازه‌های حذف‌هم‌پوشانی‌شده است؛ استقلال آماری قطعی ادعا نمی‌شود. کمتر از ۸ Match به `INSUFFICIENT_HISTORICAL_ANALOGUES` و Quantile برابر null می‌انجامد. آستانه OOD مستقل هنوز Calibration نشده و Confidence احتمال‌نما تولید نمی‌شود.

Bundle چندمقیاسی فقط کندل بلندترِ بسته و دارای availability مجاز را می‌بیند. خروجی افق‌های متفاوت بر حسب ثانیه مشخص است و کوانتایل ۳ کندل یک‌دقیقه‌ای با ۳ کندل چهارساعته میانگین گرفته نمی‌شود.

## ایندکس، ارزیابی و اجرا

ایندکس SQLite در مسیر مستقل پژوهشی ذخیره می‌شود. Manifest شامل نسخه، Hash پیاده‌سازی، فایل‌های واقعی منبع، Hash ردیف‌ها، شمارش‌ها و Missingهاست. ایندکس نهایی Immutable است؛ برای تغییر روش یا Rebuild از پوشه تازه استفاده کنید. Crash در تراکنش Build rollback می‌شود و فایل‌های اصلی آرشیو تغییر نمی‌کنند.

```powershell
conda run --no-capture-output -n shbk python -m wallex_bot.atlas_patterns build --max-windows-per-asset 250 --output reports/m8_pattern_index_build.json
conda run --no-capture-output -n shbk python -m wallex_bot.atlas_patterns search --symbol BTCTMN --resolution 15 --length 10 --method dtw --output reports/pattern_query.json
conda run --no-capture-output -n shbk python -m wallex_bot.atlas_pattern_research --max-queries 8
```

اجرای واقعی اولیه: ۲۷٬۰۴۱ پنجره، ۲۹ دارایی، ۶۸ Query تاریخی و چهار جست‌وجوی فعلی. Baselineها و روش‌ها روی Query/Label مشترک مقایسه شدند؛ هدف پژوهشِ نمونه‌ای سه کندل است. داده برای ادعای ارزش افزوده مستقل PIT/اقتصادی کافی نیست. نتایج در دو فایل `m8_pattern_retrieval_results.json` و `m8_pattern_retrieval_ablation.csv` باقی مانده‌اند؛ هیچ روش با Test انتخاب یا Promote نشده است. Pattern فعلاً فقط شواهد پژوهشی Agent است و وزن پیش‌بینی Champion را تغییر نمی‌دهد.
