# راهنمای نسخهٔ جاری WALL-E

## اجرا

از ریشهٔ مخزن در محیط موجود shbk:

```text
conda run --no-capture-output -n shbk python -m ui_backtest.app --port 8769
```

http://127.0.0.1:8769/ شامل همهٔ صفحات نمایشی و Backtest جدید است. سرور قدیمی 8768 را لازم نیست ببندید. افزونهٔ نموداری خارج از Source Manifest معامله‌گر نگهداری شده تا نشست Shadow جاری با اصلاح متن رابط باطل نشود. سرور Backtest نمی‌تواند مطالعه یا سفارش را شروع/متوقف کند؛ این قابلیت‌ها روی سرور اصلی پژوهش باقی می‌مانند.

دریافت عمومی و تحلیل خبر/FinBERT/Shadow جدا اجرا می‌شوند؛ بازکردن رابط به‌تنهایی آن‌ها را راه نمی‌اندازد. FinBERT پژوهشی است و حق رأی مسابقه به آن داده نشده. Resume تنها با سورس/مدل/محیط مطابق قرارداد همان نشست معتبر است؛ برای سورس جدید باید صریح نشست جدید ساخت و قبلی را حفظ کرد.

## دامنهٔ نمودارها

- Backtest دارای انتخاب بازه UTC، بازار BTC/ETH، مقایسه Equity/PnL/Drawdown، نقاط ورود/خروج قواعد و توصیه‌های ثبت‌شدهٔ نقش‌هاست.
- عنوان «شبیه‌سازی تاریخی» جای عنوان قبلی نمودارها را گرفته؛ داده، قواعد، سودوزیان، هزینه‌ها و مقیاس خودکار تغییر نکردند. زیان پنهان نشده است.
- قاعده‌های ثابت SMA/MACD/RSI و buy-and-hold مقایسهٔ پژوهشی‌اند؛ FinRL آموزش/اجرا نشده و این‌ها نتیجهٔ Champion معرفی نمی‌شوند.
- کارمزد و لغزش تاریخی فرض هزینه‌اند، نه رسید اجرای صرافی؛ جزئیات در [قرارداد نمودارها](milestones/BACKTEST_CHARTS_FA.md) آمده است.
- نقش‌های تحلیلی سود مستقل اندازه‌گیری‌شده ندارند؛ نمودار آن‌ها توصیه/وضعیت واقعی ثبت‌شده را نشان می‌دهد.
- بدون آرشیو معتبر و پیوسته، نمودار N/A است. Clean clone بدون دارایی‌های محلی همان نشست تاریخی را بازتولید نمی‌کند.

## وضعیت Spot

آداپتور کنترل‌شدهٔ جداگانه برای Submit/Cancel، پیگیری تجمعی، کارمزد، Reconciliation و بازیابی پیاده شده اما اجرای مثبت با Fill واقعی تأیید نشده است. Broker قدیمی همچنان HARD_DISABLED است؛ آداپتور جدید هم بدون مدارک و ARM محدود به حساب/نشست مجوز مالی ندارد. این نسخه مجوز LIVE نیست. شرایط حساب/پکیج، محدودیت دقیق بازار و صلاحیت مالی را نباید از موجودی مشابه یا پرچم ساختگی نتیجه گرفت.

موعد با درخواست صریح اپراتور به **یکشنبه ۳ آبان ۱۴۰۵، ۲۵ اکتبر ۲۰۲۶** تغییر کرد: توقف ورود ۲۲:۵۰، مرحله خروج ۲۳:۰۰ و HALT ساعت ۲۳:۵۰ تهران، برابر ۲۰:۲۰ UTC همان روز. این درخواست، تأیید مستقل تغییر قوانین برگزارکننده یا مجوز LIVE نیست. بازفعال‌سازی خودکار پس از موعد ممنوع است؛ تسویه بدون رسید Fill ادعا نمی‌شود.

تغییر موعد، سورس معامله‌گر را تغییر می‌دهد؛ نشست منجمد قبلی خودکار تمدید یا بازنویسی نمی‌شود و با سورس جدید Resume معتبر نیست. برای پژوهش با موعد تازه باید نشست جدید ساخت. پردازه‌های قدیمی پس از Restart موعد جدید را می‌خوانند. هیچ HALTED latch، مجوز قبلی یا رسید حساب پاک/بازنویسی نمی‌شود؛ اگر از قبل HALTED شده باشد همچنان بسته می‌ماند و بازبینی مستقل لازم دارد.

## انتشار

سورس، تست‌ها و مستندات commitشده پس از اسکن تاریخچه منتشر می‌شوند؛ `.env`، `pass.txt`، کلید، پاسخ خصوصی حساب، SQLite، آرشیو، وزن مدل، `.tools` و نشست‌های پژوهشی وارد انتشار نمی‌شوند. فایل‌های untracked اپراتور خودکار stage نمی‌شوند. تاریخچه بازنویسی و دادهٔ محلی پاک نمی‌شود. گزارش‌های خبری تولیدشده در اجرای دستی اپراتور، تا بررسی مستقل جزو تغییر سورس انتشار نیستند.

## تست

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
conda run --no-capture-output -n shbk python -m pytest -q
```

موفقیت تست نرم‌افزار، اثبات سودآوری یا مجوز سفارش واقعی نیست. گزارش [Backtest](milestones/BACKTEST_CHARTS_FA.md) و [موانع LIVE](milestones/LIVE_BLOCKERS_REVIEW_FA.md) محدودیت‌های شواهد را ثبت می‌کنند.

اعتبارسنجی نسخهٔ انتشار در محیط shbk: **۳۹۷ passed، ۶ skipped** در ۴۶٫۲۳ ثانیه. پاسخ HTTP فایل رابط روی پورت 8769 نیز بررسی شد: عنوان جدید حاضر و واژهٔ قبلی در عنوان‌های افزونه غایب است. Source Manifest معامله‌گر تغییر نکرده است.

تغییرنامهٔ این انتشار: عنوان نمودارها به «شبیه‌سازی تاریخی» تغییر کرد، راه‌اندازی رابط جدید به README فارسی/انگلیسی اضافه شد و نتایج عددی یا تصمیم‌ها دست‌کاری نشدند.

به‌روزرسانی بعدی موعد به ۳ آبان: تست کامل **۴۰۰ passed، ۶ skipped**؛ [گزارش اصلاح موعد](milestones/DEADLINE_EXTENSION_1405_08_03_FA.md). برخلاف اصلاح صرف متن رابط، این تغییر شامل ثابت زمانی معامله‌گر است و برای نشست‌های منجمد قبلی نیازمند نشست جدید خواهد بود.
