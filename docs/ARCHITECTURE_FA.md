# معماری واقعی فارسی / English architecture

Wallex public GET → DataSyncManager/SQLite progress → SHA/grid/closed-bucket/PIT validation → feature recipe V1/V2/V3 + independent M8 technical → observations/review → capped allocator → unchanged deterministic RiskGate → ShadowBroker/PaperAccount → hash receipts, replay, deadline forward scoring.

NewsStore retains publication, first observation, processing and availability separately. FinBERT is local NC research only; unavailable sentiment is missing, not neutral. Historical pattern retrieval uses a versioned immutable index and is evidence-only until independently validated. Neither news text nor pattern/memory can grant order authority.

Main implementation: atlas_archive/data_sync, atlas_feature_registry/provenance, atlas_deep and atlas_m5_*, atlas_news_*, atlas_patterns, atlas_agentic_review/cycle, atlas_memory, atlas_portfolio, atlas_risk/broker/shadow, atlas_study/prospective. atlas_agentic_cycle has four actual LangGraph nodes with SqliteSaver and ten structured roles, not ten LLM requests. Specialist critique precedes allocation/execution; advisory language output cannot change the numerical forecast or broker permission.

AI attribution is traceable via prediction_id, model SHA, source/quote hash, quantiles, review and intent IDs. Current Champion PatchTST is unchanged. M5 PatchTST and LightGBM plus zero and historical-quantile baselines are prospective observers; iTransformer remains research. Training target is close-to-close; forward mid-to-mid is a proxy, not executable PnL. Fee .001 per side is unverified.

Snapshot M8: 52 V3 definitions, 15 extra technical definitions, 14 news definitions, 27041 pattern windows over 29 assets. These are historical snapshot counts, not guaranteed current coverage. Confirmed Fibonacci uses right-neighbor availability; Ichimoku display shifts are not backdated; corrected SuperTrend is separate from old approximations. Recipe Champion is not silently expanded.

Memory is bounded FinMem-inspired product ranking, with observed/available/created cutoffs; BACKTEST does not write operational memory. Portfolio keeps >=80% cash, <=10% per asset/cycle turnover and <=0.1% cycle cost, subject to unchanged Gate. ADD remains blocked; REBALANCE needs individually authorized legs. Depth estimates are never exchange fills. See linked model card, policy and M8 reports for exact scopes/limitations.
