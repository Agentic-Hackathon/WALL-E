# جست‌وجوی تعاملی الگوهای تاریخی

۱. منبع: موتور موجود `atlas_patterns.PatternIndex` و `make_query` با SciPy/BSD-3-Clause و DTW محدود مستقل بازاستفاده شد؛ همان منابع و نسخه‌های ثبت‌شده در ماژول و `third_party/SOURCES.md` معتبرند. الگوریتم، شاخص قدیمی و Champion تغییر نکردند. اتصال HTTP و نمایش کندل/نمودار، کد جدید رابط روی زیرساخت فعلی‌اند؛ فریم‌ورک یا موتور تطبیق جدیدی اضافه نشد.

۲. فایل‌ها: `atlas_console.py`، `static/console_v2.js`، `static/console_v2.css` و `tests/test_pattern_explorer_real_only.py`. مسیر رابط: پژوهش هوش مصنوعی ← الگوها. فرمان اجرا:

```text
conda run --no-capture-output -n shbk python -m wallex_bot.atlas_console --port 8768
```

بازکردن http://127.0.0.1:8768/ و انتخاب الگوها، به‌جای گزارش ثابت قدیمی، درخواست فقط‌خواندنی `/api/pattern-search` را اجرا می‌کند. بازارهای BTC/ETH، رزولوشن‌های 1m/5m/15m/1h/4h، طول ۷ یا ۱۰، OHLCV/DTW/ساختار کندل و دامنه همان بازار/کل شاخص قابل انتخاب‌اند. رزولوشن یا طول بدون شاخص سازگار، به‌وضوح unavailable می‌شود و هیچ شاخص قدیمی بازنویسی نمی‌شود.

کندل واقعی مرجع، نمودار هم‌مقیاس نزدیک‌ترین‌ها، فاصله مرتب‌شده، زمان تهران، کندل‌های تاریخی و ۱۲ کندل ادامه واقعی هر نمونه نمایش داده می‌شوند. بازده‌های ۱/۳/۶/۱۲ کندل از بازده لگاریتمی ذخیره‌شده به بازده ساده تبدیل می‌شوند؛ این اعداد قبل از هزینه‌اند. برای نمایش نمودار فقط قیمت نخست هر پنجره = ۱۰۰ شده؛ این نرمال‌سازی نمایشی جای روش فاصله موتور را نمی‌گیرد. فاصله، احتمال یا درصد اطمینان نیست.

۳. تست: تمرکز روی موتور و رابط **۲۸ passed**؛ کل مجموعه **۳۸۸ passed، ۶ skipped** در ۵۶٫۰۷ ثانیه با `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`. همه کندل‌ها از آرشیو واقعی‌اند؛ تست بدون داده واقعی Skip می‌شود. تطبیق بازده با ادامه واقعی، حذف هم‌پوشانی/آینده، هم‌زمانی بسته‌شدن کندل‌ها، اعتبار ورودی، نبود ساخت فایل در آرشیو خالی و ممنوعیت promotion کنترل شدند. UI در مرورگر واقعاً باز شد و نمودار/نتایج دیده شدند. ابزار computer-use برای این تأیید بصری استفاده شد، نه برای دسترسی به کلید یا حساب.

۴. نتیجه واقعی: در بررسی BTC/15m/10/Euclidean/same، **۲۹۷ نامزد واجد شرایط و ۸ نمونه بدون هم‌پوشانی** پیدا شد؛ فاصله نزدیک‌ترین نمونه حدود **۰٫۸۱۹۹** بود. داده مرجع در همان اجرا حدود ۶ ساعت قدیمی بود؛ رابط همین را نشان داد. این endpoint عمداً هیچ دانلود یا شبکه‌ای ندارد؛ برای نتیجه بازار تازه، آرشیو باید با DataSync موجود تازه شود. زدن جست‌وجو، آرشیو فعلی را دوباره بررسی می‌کند و دانلود پنهانی نیست.

۵. محدودیت‌ها: نتیجه نه اثبات دقت پیش‌بینی/سودآوری است، نه سیگنال خریدوفروش. ادامه هر نمونه باید قبل از شروع پنجره مرجع همراه embargo پایان یافته باشد و رسید آن تا زمان جست‌وجو قابل دسترسی باشد. خروجی صرفاً پژوهشی است؛ RiskGate، LIVE، حافظه و نشست‌های ثابت تغییر نکردند. SHA منابع و payload شاخص بررسی می‌شود؛ داده خراب یا گمشده با کندل جعلی جایگزین نمی‌شود.

۶. نیاز به تصمیم جدید اپراتور نیست. برای استفاده از داده لحظه‌ای، اجرای جداگانه گردآورنده/DataSync لازم است. کلید API به مرورگر یا این مسیر وارد نمی‌شود. تصویر محلی تأیید UI: `.tools/pattern-explorer.png` (ignored؛ جزو منبع منتشرشده نیست).
