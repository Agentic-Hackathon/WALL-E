# Wallex Atlas V3.1 — رفع ریسک نشتی زمانی، آرشیو دارای شکاف و اخبار

نسخه ۳.۱ یک **پچ پژوهشی/Shadow فقط‌خواندنی** روی V3 است؛ **ثبت سفارش واقعی ندارد**.

## یافته‌های واقعی اجرای کاربر (۲۲ اکتبر ۲۰۲۶)
- بازارهای یافت‌شده: ۴۶۹؛ اسپات: ۳۷۳؛ اسپات تومان: ۱۸۷.
- اجرای محدود ۲۰بازاری: ۸۸۶ پنجره دریافت موفق، ۴۵ پنجره کش‌شده، ۲۹ پنجره شکست‌خورده؛ این اعداد تعداد کندل نیستند.
- آرشیو کل V3: ۲۹۵٬۱۳۸ ردیف کندل در تایم‌فریم‌های متعدد، ۹۵۲ incident تجمیعی.
- استراتژی‌های بررسی‌شده: ۱۹۳۶ ترکیب بازار/روش، ۴۱ پیش‌انتخاب؛ بدون تصحیح آزمون‌های متعدد.
- دو مدل GPU آموزش دیده‌اند اما **هیچ مزیت مالی خارج از آموزش اثبات نشده**. در Shadow هفت رد به علت edge ناکافی و یک RuntimeError رخ داد.
- سرویس GDELT در اجرای کاربر Timeout شده بود.

## اصلاح‌های V3.1
1. `market.candles_sparse()` پاسخ حقیقی UDF را می‌خواند؛ شکاف زمانی یک‌دقیقه‌ای را به‌عنوان نبود مشاهده گزارش می‌کند، نه خطای «رزولوشن اشتباه» که داده سالم را حذف کند. هیچ fill/interpolation انجام نمی‌شود.
2. `atlas_archive.harvest()` بازه‌های پیوستهٔ معتبر در یک پنجره ناقص را ذخیره می‌کند؛ اگر provider رزولوشن اشتباه داده باشد، آن را رد کرده و منبع واقعی یک‌دقیقه‌ای را جدا درخواست می‌کند.
3. تمام دارایی‌ها در آموزش DL یک مرز UTC مشترک دارند؛ اگر برچسب آموزشی به زمان اعتبارسنجی برسد، نمونه حذف می‌شود. گیت مدل‌های قدیمی با تقسیم محلی برقرار است.
4. مدل‌ها نسخه‌بندی می‌شوند؛ Checkpoint پیشین بازنویسی نمی‌شود. فایل `.sources.json` نام/هش فایل‌های واقعی پژوهش را ثبت می‌کند.
5. GDELT دارای fallback RSS از CoinDesk، Cointelegraph و The Block است. تاریخ خبر فقط بعد از **اولین مشاهده در سیستم** مجاز است؛ اتصال ممکن است بسته به شبکه برقرار نشود.
6. فرمان `audit-v3` وضعیت آرشیو، checkpoint، خبر و Ledger را فقط از روی فایل‌های واقعی گزارش می‌کند؛ هیچ شبکه یا API خصوصی درخواست نمی‌کند.

## نصب روی آرشیو فعلی، بدون پاک‌کردن داده‌ها
فایل `Wallex_Atlas_V3_1_PATCH_for_V3.zip` را در پوشه `D:/Hackaton/Wallex/wallex_agent_v3` استخراج و فایل‌های هم‌نام را جایگزین کنید؛ پوشه `atlas_store` **باید حفظ شود**.

```bash
conda activate shbk
python -m pytest -q
python -m wallex_bot.atlas_cli audit-v3
python -m wallex_bot.atlas_cli run --days 3 --limit-markets 20
python -m wallex_bot.atlas_cli audit-v3
```

آخرین دستور وضعیت مدل‌های global UTC و پنجره‌های ارزیابی را نشان می‌دهد. مدل‌های V3 دارای مرز اعتبارسنجی قدیمی دیگر برای Shadow انتخاب نمی‌شوند.

## محدودیت‌های باز
- خروجی بازار واقعی / GPU نسخه ۳.۱ روی سیستم محلی کاربر هنوز آزمایش نشده است؛ فقط ۲۷ تست بدون قیمت ساختگی پاس شده و ۵ تست وابسته به اتصال/داده واقعی skip شده‌اند.
- رتبه‌بندی ۴۱ استراتژی مستلزم کنترل داده‌کاوی و آزمون مستقلی است که هنوز کامل نشده است.
- مدل Transformer الزاماً مزیت سودآور ندارد و نباید از Validation Pinball مستقیماً سود را نتیجه گرفت.
- بازارهای مجاز مسابقه و API Key متعلق به حساب مسابقه برای معاملات واقعی باید به‌طور معتبر تأیید شوند؛ این پچ هیچ اجرای واقعی ندارد.
- حداقل سه کندل معتبر برای برخی مسیرهای legacy الزامی است؛ مسیر sparse جدید فقط مخصوص Archive است، نه همهٔ بک‌تست‌های قدیمی.
