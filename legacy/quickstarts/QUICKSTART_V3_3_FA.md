# Wallex Atlas V3.3 — ارزیابی آینده‌نگر بدون داده ساختگی

این نسخه فقط داده واقعی والکس را دریافت می‌کند. هیچ سفارش صرافی ارسال نمی‌کند و سود شبیه‌سازی را به عنوان سود واقعی مسابقه معرفی نمی‌کند.

## نصب روی نسخه قبلی

پچ ZIP را روی **همان پوشه `wallex_agent_v3`** استخراج و فایل‌های هم‌نام را جایگزین کنید. `atlas_store` را دست نزنید. دو مدل و آرشیو قبلی دست‌نخورده باقی می‌مانند.

```bash
bash run_v3_3.sh
```

گزارش قابل ممیزی `atlas_store/reports/v3_3_contest_readiness.json` ایجاد می‌شود. این مرحله از API Key استفاده نمی‌کند.

## آزمون زنده روی ۴۸ ساعت آینده (بدون سفارش واقعی)

```bash
python -m wallex_bot.atlas_cli watch --hours 48
```

این فرآیند باید روی کامپیوتر شما روشن بماند؛ یک بار هر ۱۵ دقیقه داده جدید را از API دریافت می‌کند و Shadow را فراخوانی می‌کند. در چرخه‌های دارای داده و دفتر سفارش معتبر، داده خام عمق بازار در `atlas_store/forward_observations.sqlite` ثبت می‌شود. برای هر مدل، نماد و کندل زمانی، تنها نخستین پیش‌بینی ثبت می‌شود. ۴۵ دقیقه بعد، **فقط وقتی یک snapshot واقعی و به‌موقع ثبت شده باشد**، بر اساس بهترین Ask ورود و Bid خروج، بازده فرضی پس از کارمزد (نه Fill واقعی) محاسبه می‌شود. هیچ قیمت جعلی و هیچ کندلی برای پرکردن شکاف ساخته نمی‌شود.

در هر زمان می‌توانید خروجی را بخوانید:

```bash
python -m wallex_bot.atlas_cli forward-report
python -m wallex_bot.atlas_cli contest-readiness
```

اجرای Shadow برای معامله واقعی مجوز ایجاد نمی‌کند. در این نسخه همچنان وضعیت `RESEARCH_ONLY_NOT_VERIFIED_FOR_LIVE_CONTEST_ORDERS` است. پذیرش یک مدل به عنوان Champion پژوهشی با آماده‌بودن برای سفارش واقعی متفاوت است.

محدودیت‌های مهم: snapshot دفتر سفارش مشاهده‌ای آنی است و Fill تضمین‌شده نیست؛ محاسبات روی قیمت بهترین سطح دفتر سفارش برای تعداد واقعیِ قابل خرید تضمین‌شده نیست. کارمزد پیش‌فرض ۰٫۱٪ در هر سمت صرفاً فرض است. پیش‌بینی‌ها بین بازارها و در زمان هم‌بسته‌اند. تعداد مشاهده زیاد معادل ۴۸ ساعت مشاهده مستقل نیست. خبرهای آرشیوشده هنوز وارد ورودی مدل عمیق نشده‌اند.

## نحوه ادامه بعد از Restart

شروع، پایان و تعداد چرخه‌های آزمایش در `atlas_store/watch_session.json` ذخیره می‌شود. اگر در میانه آزمایش برنامه را قطع و **همان دستور** را دوباره اجرا کنید، تا مهلت نخستین Session ادامه می‌یابد. این قابلیت باعث نمی‌شود قیمت یا سیگنال مفقود بازسازی شود. اگر زمان آزمایش هنگام خاموشی تمام شده باشد، فقط تسویه فرضی موقعیت کاغذیِ باقی‌مانده با Bid واقعی در صورت دسترس اجرا خواهد شد و ممکن است ناتمام گزارش شود.

برای اجرای ۴۸ساعته با داده جدید واقعی، کلید API خصوصی الزامی نیست؛ درخواست‌ها فقط خواندنی و مربوط به بازارهای اسپات تومان هستند. این یک مطالعه پژوهشی است، نه تأیید مجازبودن همه آن بازارها برای معاملات مسابقه.
